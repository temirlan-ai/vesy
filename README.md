# Балансировочная платформа (Center of Pressure) на 4 тензодатчиках

Прошивка для Arduino Nano с 4× HX711 и 4× датчиками 5 кг + Python-визуализатор центра давления.

## Файлы

| Файл                    | Назначение                                                  |
|-------------------------|-------------------------------------------------------------|
| `balance_platform.ino`  | Скетч Nano: 4 канала, индивидуальная тара/калибровка, вывод W/balX/balY (Шаги 1–6) |
| `cop_visualizer.py`     | Python-визуализатор центра давления (Шаг 7)                  |
| `requirements.txt`      | Зависимости Python                                          |
| `.venv/`                | Готовое виртуальное окружение                                |

## Распиновка

**Датчик → HX711** (на каждый из 4 каналов):

```
красный  → E+      чёрный → E-
белый    → A-      зелёный → A+      (полярность сигнала некритична)
```

**HX711 → Nano:**

```
VCC → 5V     GND → GND      (все 4 в параллель)
SCK → D6     (общий на все 4 модуля)
DT (DOUT) у каждого свой:
    Канал 0  ПЛ (перед-лево)  → D2
    Канал 1  ПП (перед-право) → D3
    Канал 2  ЗЛ (зад-лево)    → D4
    Канал 3  ЗП (зад-право)   → D5
```

Раскладка углов (вид сверху):

```
       ПЕРЕД
    ПЛ ----- ПП
    |         |
    ЗЛ ----- ЗП
       ЗАД
```

## Прошивка (Arduino IDE)

1. Установи драйвер **CH340** на ПК.
2. Library Manager → поставь библиотеку **HX711_ADC** (Olav Kallhovd).
3. Tools → Board: **Arduino Nano**, Processor: **ATmega328P** (если не льётся — `ATmega328P (Old Bootloader)`).
4. Залей `balance_platform.ino`.

## Команды по Serial (9600 бод)

| Команда        | Действие                                                        |
|----------------|-----------------------------------------------------------------|
| `t`            | тарировать (обнулить) все 4 канала                              |
| `c <mass>`     | **общая калибровка**: груз `mass` (г) в центре платформы → один коэффициент на все 4 датчика. Пример: `c 2000` |
| `k<ch> <mass>` | (опц.) откалибровать один канал `ch` (0..3) эталоном на его углу. Пример: `k0 1000` |
| `z`            | показать текущие калибровочные коэффициенты                     |
| `r`            | сбросить все калибровки к 1.0                                   |

Коэффициенты сохраняются в EEPROM — калибровать нужно один раз.

### Порядок калибровки (основной — общий)

1. Убери всё с платформы → отправь `t` (обнуление).
2. Положи **один известный груз точно в центр** платформы (например 2 кг).
3. Отправь `c 2000` (масса в граммах). Скетч подберёт один коэффициент так,
   чтобы сумма 4 датчиков = масса эталона.
4. Проверь: убери груз → `t`; положи груз обратно — суммарный `W` должен
   совпасть с эталоном, а при сдвиге груза нагрузка перетекает между углами.

> Общей калибровки достаточно, потому что баланс измеряет **соотношения**
> нагрузок. Если нужна максимальная точность по каждому углу — используй
> поканальную калибровку `k0..k3` (груз поочерёдно на каждый угол).

## Формат вывода (CSV)

```
PL,PP,ZL,ZP,W,balX,balY
```

- `PL,PP,ZL,ZP` — нагрузка каждого датчика, **кг**
- `W` — суммарный вес, **кг**
- `balX` — смещение вправо, % (`+` вправо / `-` влево)
- `balY` — смещение вперёд, % (`+` вперёд / `-` назад)

Проверка логики: груз в центр → `balX≈balY≈0`; сдвиг вправо → `balX` растёт.

## Визуализатор (Шаг 7)

venv уже создан и зависимости установлены. Закрой Serial Monitor в Arduino IDE (порт занят), затем:

```powershell
& ".venv\Scripts\python.exe" cop_visualizer.py
```

Скрипт сам найдёт COM-порт (или спросит, если их несколько). Можно указать явно:

```powershell
& ".venv\Scripts\python.exe" cop_visualizer.py COM5
```

Откроется окно matplotlib с точкой центра давления, следом и текущим весом.

### Пересоздать окружение (если нужно)

```powershell
py -m venv .venv
& ".venv\Scripts\python.exe" -m pip install -r requirements.txt
```

## Важно (риски)

- **Перегрузка** — предел 5 кг на датчик. Никаких людей/прыжков/резких тычков. Общий вес ≤ ~15 кг.
- Верхняя пластина должна быть **жёсткой**, датчики — максимально в одной плоскости.
- Балка меряет только при правильном монтаже: один конец закреплён, груз на другом, между концами спейсеры (стрелка по нагрузке).
- Калибровка **по каждому каналу отдельно** — 4 разных коэффициента.

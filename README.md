# Балансировочная платформа (Center of Pressure) на 4 тензодатчиках — v2

Прошивка для Arduino Nano с 4× HX711 и 4× датчиками **MH26G4MH782 (100 кг)** + визуализаторы центра давления (matplotlib и веб-экран).

## Платформа v2

- Лист алюминия 2 мм на раме жёсткости из профтрубы 25 мм.
- Размер **800 × 600 мм**, высота 56 мм (датчики 26, верхняя пластина 2, промежуточная 2, профтруба 25).
- **800 мм — влево/вправо (ось X), 600 мм — вперёд/назад (ось Y).**
- 4 датчика по 100 кг → платформа держит **~400 кг**.

Центры датчиков (отступ от угла листа, мм) и координаты от центра платформы (+X вправо, +Y вперёд):

| Датчик | по длине (800) | по ширине (600) | X, мм  | Y, мм  |
|--------|----------------|-----------------|--------|--------|
| ПЛ     | 35             | 37.6            | −365.0 | +262.4 |
| ПП     | 35             | 35              | +365.0 | +265.0 |
| ЗЛ     | 36             | 39              | −364.0 | −261.0 |
| ЗП     | 38             | 36              | +362.0 | −264.0 |

Опоры образуют почти прямоугольник ≈ 73 × 53 см. Вся геометрия живёт в одном
файле — **`platform_geometry.py`**. Перемерил датчики → поправь `SENSOR_OFFSETS_MM`
там, и мост, и оба экрана подхватят новые координаты. Проверка:

```powershell
& ".venv\Scripts\python.exe" platform_geometry.py
```

## Распиновка (не изменилась)

**Датчик → HX711** (на каждый из 4 каналов):

```
красный  → E+      чёрный → E-
белый    → A-      зелёный → A+      (полярность сигнала некритична)
```

**HX711 → Nano:**

```
VCC → 5V     GND → GND      (все 4 в параллель)
SCK → D6     (общий на все 4 модуля)
DT (DOUT) у каждого свой:
    Канал 0  ПЛ (перед-лево)  → D2
    Канал 1  ПП (перед-право) → D3
    Канал 2  ЗЛ (зад-лево)    → D4
    Канал 3  ЗП (зад-право)   → D5
```

Раскладка углов (вид сверху):

```
              ПЕРЕД
    ПЛ ---------------- ПП
    |      800 мм       |  600 мм
    ЗЛ ---------------- ЗП
              ЗАД
```

## Прошивка (Arduino IDE)

1. Установи драйвер **CH340** на ПК.
2. Library Manager → поставь библиотеку **HX711_ADC** (Olav Kallhovd).
3. Tools → Board: **Arduino Nano**, Processor: **ATmega328P** (если не льётся — `ATmega328P (Old Bootloader)`).
4. Залей `balance_platform/balance_platform.ino`.

## Команды по Serial (9600 бод)

| Команда        | Действие                                                        |
|----------------|-----------------------------------------------------------------|
| `t`            | тарировать (обнулить) все 4 канала                              |
| `c <mass>`     | **общая калибровка**: груз `mass` (**кг**) в центре платформы → один коэффициент на все 4 датчика. Пример: `c 50` |
| `k<ch> <mass>` | (опц.) откалибровать один канал `ch` (0..3) эталоном (кг) над этим датчиком. Пример: `k0 20` |
| `z`            | показать текущие калибровочные коэффициенты                     |
| `r`            | сбросить все калибровки к 1.0                                   |
| `d`            | диагностика: мгновенные кг и размах шума по каналам (повторно — выкл.) |

Коэффициенты сохраняются в EEPROM — калибровать нужно один раз.
**После смены датчиков на 100 кг старые коэффициенты не подходят** — сделай `r`, затем калибровку заново.

### Порядок калибровки

1. Убери всё с платформы → `t`.
2. Положи известный груз **точно в центр** платформы (например 50 кг или человек известного веса).
3. Отправь `c 50` (масса в кг).
4. Проверка: убери груз → `t`; верни груз — `W` совпадает с эталоном.
   Поставь груз над каждым датчиком по очереди — центр давления уходит в этот угол.
5. Порог шума `NOISE_GATE` (0.2 кг): посмотри размах в режиме `d` в покое и
   поставь чуть больше, если точка «дрожит» на пустой платформе.

## Формат вывода (CSV)

```
PL,PP,ZL,ZP,W,balX,balY
```

- `PL,PP,ZL,ZP` — нагрузка каждого датчика, **кг**
- `W` — суммарный вес, **кг**
- `balX` — доля смещения вправо, % (`+` вправо / `-` влево)
- `balY` — доля смещения вперёд, % (`+` вперёд / `-` назад)

Если канал > 90 кг, раз в секунду дополнительно идёт строка `WARN OVERLOAD <канал> <кг>`.
Центр давления в сантиметрах считает ПК по реальным координатам датчиков.

## Важно (риски)

- **Перегрузка** — предел **100 кг на датчик**, вся платформа ~400 кг. Человек, стоящий над одним углом,
  нагружает в основном один датчик — следи за предупреждением `ПЕРЕГРУЗ`. Прыжки и удары
  дают кратные пиковые нагрузки — при ударных нагрузках нужны упоры-ограничители хода.
- Все 4 датчика должны стоять в одной плоскости, рама — без перекоса, иначе один угол «висит».
- Калибровка общая (один коэффициент); для максимальной точности по углам — `k0..k3`.
